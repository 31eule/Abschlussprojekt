# App-Projekt: Elektronische Patientenakte
In der elektronniaschen Patientenakte werden medizinische Daten von den Patienten gespeichert. Es können sowohl die Ärzte als auch die Patienten auf die Daten zugreifen. Ärzte haben Zugriff auf Daten verschiedener Patienten. Außerdem können Sie neue Daten (von zum Beispiel einem EKG) hinzufügen und sich dauerthaft ändernde Größen, wie Größe und Gewicht anpassen. EKG-Daten werden selbstständig ausgewertet nach bestimmten Erkrankungen. Patienten haben nur Zugriff auf ihre eigenen Dateien. Sie können sich über die diagnostizierten Erkrankungen informieren und erhalten Sport- und Ernährungshinweise.

# Installation der App
Um das Projekt auszuführen, müssen zunächst Python und das Python-Paketverwaltungstool pdm installiert werden (z.B. mit dem Befehl pip install pdm). Anschließend wird das Projekt mit dem Befehl pdm init initialisiert. Dabei gibt man grundlegende Informationen wie Projektname, Version, Beschreibung und Autor an.

Nach der Initialisierung werden die benötigten Abhängigkeiten, wie z. B. streamlit, plotly, numpy, pandas und matplotlib, mit pdm add installiert. Das Projekt wird anschließend von GitHub geklont und man erhält alle notwendigen Dateien. Nun kann das Streamlit mit dem Befehl streamlit run app.py zum Laufen gebracht werden. Die Streamlit App wird nun im Browser geöffnet.

Die App kann auch über den Link [text](https://abschlussprojekt-3h3nheqivmgflya8ppvxzx.streamlit.app/) geöffnet werden im Browser ohne weitere Installationen.
